## 🎯 О проекте

Это пет-проект для портфолио, созданный в рамках изучения:

- **Чистый HTML5 + CSS3** — без фреймворков
- **Адаптивная вёрстка** — работает на всех устройствах
- **CSS-анимации** — плавание шара, тряска, свечение, звёзды
- **Нативный JavaScript** — обработка ввода, генерация предсказаний, анимации
- **Дизайн в Sai 2** — проработанный визуал с ведьмой и магическим шаром

---

## 🧙‍♀️ Особенности

| Фича | Описание |
|------|----------|
| **Ведьма на весь экран** | PNG-изображение с прозрачным фоном и плавным затемнением |
| **Магический шар (PNG)** | Кастомный шар с текстурой, бликами и полупрозрачностью |
| **Анимация плавания** | Шар медленно покачивается, создавая мистическую атмосферу |
| **Тряска шара** | При запросе шар вибрирует, имитируя магический процесс |
| **Свечение** | При появлении предсказания шар загорается фиолетовым светом |
| **Текст внутри шара** | Предсказание появляется поверх PNG с красивым текстовым свечением |
| **Звёздное небо** | Мерцающие звёзды на фоне |
| **Адаптив** | Под десктоп, планшет и мобильные устройства |
| **Интерактив** | Ввод вопроса → Enter или кнопка → предсказание |
